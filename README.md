# A股一年持有概率研究

这是《中国A股随机买入并持有一年：赚钱还是亏钱？》的可交互网页版。

- 研究范围：上海、深圳A股；主板、科创板、创业板。
- 数据截止：2026-09-04。
- 主要口径：随机股票、等权投资组合、全市场市值加权。
- 研究性质：历史统计与概率分析，不构成收益承诺或个性化投资建议。
